## Featured Projects

### [Customer Retention Analytics](https://github.com/anushkanaidu/customer-retention-analytics) · [Live Dashboard](https://anushka-customer-retention.netlify.app/)
> RFM segmentation and future-inactivity prediction that turns model scores into retention priorities.

- Cleaned **776,594 transactions** from **5,852 customers** (UCI Online Retail II) and built four RFM segments
- Predicted 180-day purchase inactivity with a **time-based cutoff to prevent target leakage**; Random Forest reached **ROC-AUC 0.795** and **recall 0.748** on held-out data
- Found that **1,204 high-value, lower-risk customers held 78.5% of spend**, while only 34 were high-value and high-risk, which supports a protect-vs.-intervene strategy
- Built with **Python · scikit-learn · React · Node.js/Express · Gemini API** (LLM used for interpretation only, never for scoring)

### [OpsCore — HR Analytics Dashboard](https://github.com/anushkanaidu/opscore-dashboard) · [Live Dashboard](https://opscore-dashboard.netlify.app)
> Full-stack HR lifecycle dashboard with risk flags and LLM-generated summaries, built on a synthetic 500-employee dataset.

- Flags **52 background-check SLA breaches**, **206 high flight-risk employees**, and a **50.3% compliance gap**
- Covers hiring, onboarding, compliance, and offboarding, with named ownership for every breach
- Built with **React · TypeScript · Tailwind · Gemini & Claude APIs**, deployed via GitHub → Netlify CI/CD
